# 2D Futbol Oyunu

Bu depo, Pygame kullanılarak geliştirilmiş basit bir 2D futbol oyununu içerir. Oyunda mavi renkli oyuncuyu kontrol ederek sarı topu rakip kaleye göndermeye çalışırsınız.

## Kurulum

1. Gerekli bağımlılıkları kurun:

   ```bash
   pip install -r requirements.txt
   ```

2. Oyunu başlatın:

   ```bash
   python main.py
   ```

## Kontroller

- **WASD** veya **Ok Tuşları**: Oyuncuyu hareket ettirir.
- **Space**: Topa şut çeker.

Yapay zeka, topa doğru hareket ederek topa vurur. Gol olduğunda skor güncellenir ve oyun ortadan yeniden başlar.
